# dep-vet tap

Homebrew formulae for [dep-vet](https://github.com/nassih-yassine/Dep-Vet), a
dependency risk scanner for npm, PyPI, crates.io, Go, JSR, RubyGems, NuGet,
Maven, and Composer.

```sh
brew install nassih-yassine/tap/dep-vet
```

`dep-vet --version` confirms the install. The formula installs a prebuilt
binary, so there is no Rust toolchain requirement.
